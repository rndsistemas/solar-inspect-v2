# SOLAR INSPECT — Fase 2

Protótipo avançado nativo para iPhone em SwiftUI.

## Estrutura
- Login e perfis
- Dashboard
- Mapa georreferenciado do complexo
- Parques > blocos > mesas/trackers > strings > módulos
- Ficha e histórico do módulo
- Inspeção visual, elétrica, drone e termografia
- Fotos/evidências com metadados
- QR Code
- Ordens de serviço
- Assinatura digital
- Importação KML/KMZ/GeoJSON/CSV
- Estrutura para DWG/DXF convertido
- Notificações
- Sincronização offline/nuvem
- API/ERP

## Tecnologias previstas
- SwiftUI
- MapKit
- CoreLocation
- PhotosUI
- AVFoundation (QR/câmera)
- UserNotifications
- Supabase
- PostgreSQL + PostGIS
- Storage em nuvem
- REST API

## Produção
Este pacote implementa um protótipo navegável e a arquitetura-base. Supabase, PostGIS,
push remoto, processamento térmico/IA, importadores GIS completos, assinatura com
validade jurídica e integrações ERP exigem credenciais, backend e configuração de produção.

Abra os arquivos Swift em um projeto iOS 17+ no Xcode.
